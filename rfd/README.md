# Replica Control design discussions

These repository-local Requests for Discussion follow the structure of
[Teleport's RFD guidance](https://github.com/gravitational/teleport/blob/master/rfd/0000-rfds.md).
Their numbers belong to this independent educational repository; they do not
reserve numbers or record approvals in the Teleport project.

| RFD | Review state | Scope |
|---|---|---|
| [0001 - Replica Control system design](0001-replica-control.md) | Draft; reviewers not assigned | Levels 1–5, APIs, controller, security, local development and CI |

RFD 0001 documents an existing reference implementation for review. Its `draft`
state describes the document's review status, a local adaptation of the upstream
process. It must not be read as evidence of Teleport design approval. Record
review decisions and named approvers before changing its state.

The [implementation guide](../docs/DESIGN.md) is the shorter technical overview;
the [validation index](../VALIDATION.md) identifies dated execution evidence.
